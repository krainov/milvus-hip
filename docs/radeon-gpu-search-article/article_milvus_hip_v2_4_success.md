## 4. What would count as success

A kernel in a notebook would not have helped that team. They need a Milvus GPU index they can build, load, and search from the normal client, on the Radeon already in the case.

If neighbour IDs on the HIP build failed the same recall check against exact kNN as the official NVIDIA build, we would stop. Speed without the right IDs is not a result. We also wanted a repeatable speed number against a same-generation NVIDIA card — not a claim that one GPU always wins.

The plots are in the results section. This was only the bar.
