## 4. What would count as success

A library demo on the GPU would not have helped the team. They need a Milvus GPU index they can build, load, and search from the normal client, on the Radeon already in the machine.

If neighbour IDs on the HIP build had failed the same recall check against exact kNN as the official NVIDIA build, we would have stopped. Speed without the right IDs is not a result. We also wanted a repeatable speed number against a same-generation NVIDIA card — not a claim that one GPU always wins.
